# WORLD — Godot / Debian

Questa è la nuova versione nativa del progetto, nel branch `godot`.
La versione web precedente resta disponibile nel branch `main`.

## Avvio su Debian

1. Installa Godot 4 (versione 4.3 o successiva) dal pacchetto Debian/Flatpak ufficiale.
2. Clona il repository e passa al branch `godot`.
3. Apri questa cartella in Godot tramite **Importa progetto** selezionando `project.godot`.
4. Premi F6/F5 per avviare la scena.

## Controlli

- WASD: movimento
- Mouse: visuale
- Shift: corsa
- Esc: libera il mouse; clic sinistro per riprenderlo

## Stato

- Progetto nativo Godot 4.
- Prima area in costruzione: **Tre Fiumi**, città commerciale alla confluenza dei tre fiumi.
- Scala umana: personaggio 1,76 m, camera 1,62 m, porte 2,05 m.
- Collisioni fisiche su edifici e strutture.
- La città viene costruita per quartieri, così da poter introdurre caricamento progressivo e livelli di dettaglio.

Gli audio originali e il romanzo restano nel repository.
